## What's here

**[PipettePilot](https://github.com/marikraft/PipettePilot)**\
Can you let an LLM drive a lab robot? Kind of.

I built PipettePilot to explore what happens when an LLM generates liquid-handling instructions that look reasonable but violate physical constraints. With the LLM alone, up to 40% of impossible plans passed through without being flagged. Adding a deterministic validation layer brought that down to zero in the evaluated cases.
